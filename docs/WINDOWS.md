# Windows 11: работа 24/7

## 1. Отключить сон и гибернацию

PowerShell (от имени администратора):

```powershell
powercfg /change standby-timeout-ac 0      # не засыпать от сети
powercfg /change hibernate-timeout-ac 0    # не уходить в гибернацию от сети
powercfg /change monitor-timeout-ac 15     # монитор гасить можно
powercfg /hibernate off                    # (опционально) полностью отключить гибернацию
powercfg /requests                         # проверить, что ничего не мешает
```

Или через GUI: Параметры → Система → Питание и батарея → «Экран и спящий режим» →
«При питании от сети переводить устройство в спящий режим через» = **Никогда**.

Дополнительно:
* Параметры → Центр обновления Windows → Дополнительные параметры → **Период активности** —
  укажите часы, чтобы Windows не перезагружалась в торговое время (после перезагрузки задача
  стартует сама при входе в систему — настройте автологин или используйте вариант NSSM).
* Ноутбук: «Действие при закрытии крышки» = «Действие не требуется» (Панель управления → Электропитание).
* Сетевой адаптер: Диспетчер устройств → адаптер → Управление электропитанием → снять
  «Разрешить отключение этого устройства для экономии энергии».
* Синхронизация времени должна быть включена (Параметры → Время и язык → «Установить время автоматически»).

Если компьютер всё же уснёт, бот после пробуждения сам переподключится, догрузит пропущенные
свечи, сверит позиции с биржей и восстановит сессию. OCO-ордера SL/TP на бирже работают и пока ПК спит.

## 2. Вариант A — Task Scheduler (рекомендуется для домашнего ПК)

```powershell
cd C:\bots\tradingbot
powershell -ExecutionPolicy Bypass -File scripts\install_task.ps1
Start-ScheduledTask -TaskName OKXBot
```

Скрипт регистрирует:
* **OKXBot** — триггер «при входе пользователя», действие `.venv\Scripts\pythonw.exe run_forever.py`
  (без окна консоли), «Перезапускать при сбое: каждую 1 мин, до 999 раз», без ограничения времени
  выполнения, без остановки при работе от батареи, «не запускать новый экземпляр».
  `run_forever.py` сам перезапускает `main.py` при падении (пауза 10 с … 5 мин), а Task Scheduler
  перезапускает и сам супервизор.
* **OKXBot-Watchdog** — каждые 5 минут `scripts\watchdog.py`: если `data\heartbeat.json` не обновлялся
  > 5 мин — всплывающее уведомление Windows и запись в `logs\watchdog.log` (одно на инцидент +
  уведомление о восстановлении).

Вручную через GUI (taskschd.msc) — те же настройки: «Создать задачу» → Общие: «Выполнять только для
вошедшего пользователя»; Триггеры: «При входе в систему»; Действия: программа
`C:\bots\tradingbot\.venv\Scripts\pythonw.exe`, аргументы `run_forever.py`, рабочая папка
`C:\bots\tradingbot`; Условия: снять «Запускать только при питании от сети»; Параметры: «При сбое
перезапускать через 1 мин», «Останавливать задачу, выполняемую дольше» — снять.

Удаление: `powershell -ExecutionPolicy Bypass -File scripts\uninstall_task.ps1`.

## 3. Вариант B — служба через NSSM

Служба стартует при загрузке Windows без входа пользователя.

1. Скачайте NSSM (https://nssm.cc/download), положите `nssm.exe` в `PATH` или в `scripts\`.
2. Командная строка **от администратора**:
   ```bat
   cd C:\bots\tradingbot
   scripts\install_nssm.bat
   ```
   Служба `OKXBot`: `python.exe main.py`, автозапуск, перезапуск при любом выходе через 10 с
   (кроме кода 3 «уже запущен»), stdout/stderr в `logs\service.log` с ротацией, остановка через Ctrl+C
   (бот сохраняет состояние).
3. Управление: `nssm start|stop|restart OKXBot`, `nssm edit OKXBot`, удаление `nssm remove OKXBot confirm`.

С NSSM используйте `nssm stop OKXBot` вместо `stop.bat`. Watchdog можно оставить в Task Scheduler
(вторую часть `install_task.ps1`), либо создать задачу вручную.

## 4. start.bat / stop.bat

* `start.bat` — запускает `run_forever.py` через `pythonw.exe` (фон, без окна) и открывает интерфейс
  в браузере (по умолчанию http://127.0.0.1:8765). Если вкладку закрыли — просто откройте адрес снова.
* `stop.bat` — создаёт файл `SHUTDOWN`; бот штатно завершается (позиции **не** закрываются, сессия
  восстановится при следующем старте), супервизор видит `SHUTDOWN` и не перезапускает процесс.
  Если бот не завершился за 60 с — `taskkill`.
* Аварийно закрыть все позиции: кнопка **«Стоп»** в интерфейсе или пустой файл `STOP` в папке проекта
  (`type nul > STOP`, работает, даже если интерфейс не открывается). Удалите файл, чтобы снова
  разрешить включение trader.

## 5. Логи

* `logs\bot.log` — всё (ротация 10 МБ × 10), `logs\errors.log` — предупреждения и ошибки,
  `logs\console.log` — вывод супервизора и необработанные трейсбеки.
* Просмотр в реальном времени: `Get-Content logs\bot.log -Wait -Tail 50`.
